# academic-site

Static academic website for Yoolkyu Park, built with Astro.

The current design intentionally keeps the feel of an old personal mathematics homepage:
plain HTML structure, very light CSS, and no unnecessary interactivity.

## Commands

```bash
npm install
npm run dev
npm run build
```

## Deploying to Cloudflare Pages

- Root directory: `/`
- Build command: `npm run build`
- Output directory: `dist`

## Main files

- `src/pages/index.astro`
- `src/pages/research/index.astro`
- `src/pages/publications/index.astro`
- `src/pages/notes/index.astro`
- `src/pages/cv/index.astro`
- `src/styles/academic.css`
